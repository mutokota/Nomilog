## 1. サービス概要
- **サービス名**：Nomilog（飲みログ）  
- **目的**：居酒屋や飲み会での思い出を **地図＋一覧＋カレンダー** で記録・振り返り  
- **特徴**：
  - 写真やコメントでその日の飲み会を残せる  
  - カレンダーから日付ごとに思い出を振り返り  
  - 「どの店に、いつ、誰と行ったか」を簡単に整理できる  
- **対象端末**：スマホ優先（レスポンシブ対応）

---

## 2. 主要ユースケース
1. 飲み会当日に「この店で飲んだ」と記録（現在地→住所補完→コメント・タグ）  
2. 過去の飲み会を地図／一覧／カレンダーから見返す  
3. タグ（例：新年会・会社飲み・友人）やカテゴリで検索・フィルタ  

---

## 3. 機能要件（MVP）

### 登録/編集
- 店名（必須）、コメント（任意）、画像1枚（任意）  
- **現在地取得 → 緯度・経度保存**（権限ダイアログあり）  
- **逆ジオコーディングで住所補完**（ユーザー編集可）  
- タグ（複数可、自由入力。例：同席者、イベント名）  
- カテゴリ（単一選択、例：居酒屋、焼肉、バー、鍋）  
- 訪問日（`visited_at`、デフォルトは今日）  
- 地図上のピン微調整（ドラッグで補正）  

### 表示・振り返り
- **地図表示**（訪問店をピン表示、タップで詳細カード）  
- **一覧表示**（カード形式、店名＋訪問日＋写真サムネ）  
- **詳細表示**（地図ミニビュー＋住所＋タグ＋カテゴリ＋コメント＋画像＋訪問日）  

### カレンダー表示
- **月/週切替**（モバイルでは週表示が基本）  
- 日付セルに訪問件数をドット表示  
- 日付タップで「その日の訪問リスト」展開（カード形式）  
- 前月/翌月切替 → 集計API呼び出し  
- 長押しで「この日で新規作成」

### 検索・フィルタ
- キーワード検索（店名・コメント・タグ）  
- フィルタ：カテゴリ、タグ（複数）  
- 地理フィルタ：地図範囲  
- 並び替え：新着／訪問日順／名前順  

### マップ体験
- ピンクラスタリング  
- カテゴリ別ピン色／アイコン  
- 現在地表示（青点＋精度円）  
- 地図長押しで仮ピン配置 → 登録フォームに反映  

---

## 4. 非機能要件
- **性能**：  
  - 初期表示 LCP ≦ 3s  
  - 操作応答 ≦ 100ms  
- **セキュリティ／プライバシー**：  
  - HTTPS必須  
  - 位置情報利用の目的を明示（非公開保存がデフォルト）  
- **データ保全**：  
  - 日次バックアップ  
  - CSV/JSON エクスポート（MVPまたは直後）  
- **ログ/計測**：登録数、検索回数、カレンダー選択回数（匿名）

---

## 5. データ項目
- **訪問記録（visits）**  
  - id  
  - store_name  
  - comment  
  - image_url  
  - lat / lon / accuracy  
  - formatted_address  
  - category_id  
  - tags[*]  
  - visited_at（訪問日時）  
  - created_at / updated_at  

- **タグ**  
  - id / name（ユニーク）

- **カテゴリ**  
  - id / name（固定集合）

---

## 6. 位置関連の方針
- **現在地取得のみ**採用（フォワードジオ不要）  
- 逆ジオで住所補完（編集可能）  
- ピンはドラッグで微調整  

---

## 7. 画面一覧（MVP）
1. **ホーム（タブ切替）**  
   - Map：地図  
   - Calendar：月/週カレンダー＋日別リスト  
   - List：検索・フィルタ反映の一覧  

2. **登録／編集**  
   - 店名、コメント、写真、タグ、カテゴリ、訪問日、現在地取得→住所補完、地図微調整  

3. **詳細**  
   - 店舗情報（地図・写真・タグ・コメント・訪問日）＋編集導線  

---

## 8. スコープ外（現時点）
- フォワードジオコーディング（住所/店名→座標）  
- 公開共有／他ユーザーとのコラボ  
- 画像複数枚、営業時間自動取得  
- Googleカレンダー連携（将来拡張）

---

## 9. 受け入れ基準（抜粋）
- 現在地許可がなくても登録画面は開ける（ただし位置取得は不可表示）  
- 訪問日デフォルト=今日だが、手動変更可能  
- カレンダー選択日と地図・一覧表示が一致する  
- スマホ幅（360〜430px）で操作が折り返しなし
